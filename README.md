# AI Augmented Credit Risk Analysis | Python, MySQL, Power BI & Gemini API

## 📌 Project Overview
This project analyzes loan and borrower data to identify loan default patterns and understand factors associated with credit risk. It combines data analysis, SQL queries, interactive visualizations, and Generative AI to turn raw data into meaningful business insights.

## 🎯 Objectives
- Analyze loan default rates across different borrower and loan categories.
- Identify patterns related to loan grades, loan burden, loan purpose, and homeownership.
- Visualize key credit risk metrics using Power BI.
- Generate AI-assisted summaries of analytical findings using the Gemini API.

## 🛠️ Tools & Technologies
- **Python:** Pandas, NumPy, Matplotlib
- **Database:** MySQL
- **Visualization:** Power BI, DAX
- **Generative AI:** Google Gemini API
- **Environment:** Jupyter Notebook

## 📊 Project Workflow
1. **Data Cleaning:** Prepared the dataset for analysis using Python.
2. **Exploratory Data Analysis:** Examined loan characteristics and default patterns.
3. **SQL Analysis:** Queried the cleaned dataset to explore risk-related metrics.
4. **Dashboard Development:** Designed Power BI visualizations to present key findings.
5. **AI Integration:** Used the Gemini API to generate concise summaries from selected analytical results.

## 🔍 Key Findings
- Loan grade D had a default rate of approximately **59.06%**, compared with **9.96%** for grade A.
- The high loan-burden group had a default rate of approximately **70.44%**, compared with **11.75%** for the low-burden group.
- Default rates varied across loan purposes and homeownership categories.
- The average interest rate was higher for defaulted loans than for non-defaulted loans in the analyzed dataset.

## 🤖 Generative AI Integration
The Gemini API was used to convert selected statistical findings into short, readable summaries. Basic output checks were applied to verify that responses were non-empty and contained expected figures. These checks do not guarantee complete factual accuracy.

## 💼 Business Value
The analysis helps stakeholders explore patterns in loan defaults, compare borrower segments, and communicate findings through dashboards and AI-assisted reporting.

## ⚠️ Limitations
- Findings describe associations in the dataset and do not establish causation.
- The analysis does not predict individual borrower defaults.
- AI-generated summaries may require manual verification.
